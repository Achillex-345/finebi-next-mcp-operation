## A-01: 新老客堆积柱 + 总销售额折线
- Prompt：在 FineBI Next「产品演示get-started / 标准产品演示」项目里，用「示例 - 订单数据_客户订单明细」做一个图：柱子是新老客贡献的销售额，堆积显示；再加一条折线显示总销售额，不拆分。
- 预期要点：

  - 先给业务设计，不先给表结构或 DSL：结果指标与指标链（客资量 × 转化率 = 签约客户数，× 客单值 = 营业额）→ 判断逻辑（目标达成率、环比、同比）→ 时间切片（日期区间）→ 维度切分（大区 → 省 → 区域 → 门店）→ 历史趋势（近 12 个月，不随切片）→ 业务归因（渠道、商品等过程板块）；
  - 说明归因板块单列的两个理由：从结果视角转到归因视角；这些维度会让主骨架扇出；
  - 链上缺信息的（有没有目标、归因看哪些过程数据）向用户提问；
  - 再给建模设计（骨架粒度、目标摊法、子表）和计划态结构图，等用户确认；DSL 不在这一步出现。
- 关联决策：D-043、D-032

## A-19: 建完看板后目视核验，用户没点名浏览器
- Prompt：看板已经保存了，你去目视核验一下。
- 预期要点：
  - 先用 Chrome 插件（用户自己的 Chrome，登录态在用户手里），在自己新开的标签页里只看不存；
  - 只有当前会话没有 Chrome 插件工具、或连不上浏览器时，才退回内置浏览器，并在回复里说明改用了内置浏览器；
  - 停在登录页时请用户登录，不代填账号和验证码；
  - 看板用「预览」看，等约 20 秒再截图。
- 关联决策：D-003

## A-20: 给看板上的表格加“动态指标”切换
- Prompt：项目、品类、SKU 三张表要能在发货金额 / 毛利额 / 实发数量之间切换，你给我加上。
- 预期要点：
  - 先说明切换控件 MCP 写不了，需要用户授权在界面操作，且界面保存后 Markup 不可再读写（K-17），所以放在看板最后一步；
  - 图表侧用 `dynamicField` 定义，每张图的动态字段起不同名字（如“<对象>动态数值”），不要几张图都叫同一个名字；
  - 界面：添加筛选器 → 下拉框 → 属性 → 绑定参数 → 「动态字段」页签 → 选对应图的动态字段；默认值“自动继承”即 `.using(...)` 的取值；
  - 编辑态下拉点不开，切换效果在「预览」里核验；MCP 回读看不到这个绑定，不能拿回读当证据。
- 关联决策：D-044

## A-21: 多轮改版，每轮都要在浏览器里看效果
- Prompt：指标卡和趋势图我又改了一版要求，你改完在 Chrome 里看一下效果。
- 预期要点：
  - 只看效果时打开预览页，不进编辑器；上一轮已开的预览页就在原标签页刷新复用，不再新开；
  - 「预览」按钮另开了标签页时，关掉原编辑器标签页；
  - 被“离开此网站？”拦住时，判断能否放弃本地状态后在原标签页继续，不靠新开标签页绕开；
  - 核验结束关掉自己开的多余标签页，最多留一个，不动用户自己的标签页。
- 关联决策：D-045
