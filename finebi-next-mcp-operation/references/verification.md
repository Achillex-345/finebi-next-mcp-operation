# 核验规范

## 回读能证明什么

| 证据 | 回读能否证明 | 说明 |
|---|---|---|
| 资产存在、READY | 能 | `calculationStatus` |
| 字段、类型、排序配置 | 能 | “编码 / 排序”段；排序显示为内部编码，如 `<维度>$$1$$0$$0 ↓`，自定义顺序也显示为 ↓，以目视为准 |
| 聚合数字 | 能，但按最细粒度 | 预览数据是 x × 颜色维度 等全部维度组合，不是渲染后的系列 |
| 系列是否被拆分、堆叠顺序 | 不能 | 必须目视 |
| 颜色、样式、标签位置 | 不能 | 回读不返回样式 |

指标类数字（比率、合计）在图上按 x 汇总，回读预览却是最细粒度：按指标口径用预览数据重算 x 级结果（如 Σ分子 ÷ Σ分母），与图上标签逐个比对（D-014）。

逻辑类分析表（打标签、窗口计算）回读后，单个对象抽样不够（D-024）：用一个**全量不变量**核对，例如“每个对象的首次标签只出现在一个周期里”“各分类合计 = 总量”，并至少再抽一个跨越判断边界的对象。全量重写前先 `get_project_asset_definitions` 反读，检查平台是否改写了步骤（如自动补 orderBy）。

## 目视：Chrome 插件优先（D-003）

默认用 Chrome 插件：用户的登录态在自己的 Chrome 里，内置浏览器经常停在登录页。当前会话没有 Chrome 插件工具、或连不上浏览器时，才退回内置浏览器，并告诉用户改用了内置浏览器。两者都只看不存。

### 内置浏览器（Chrome 插件不可用时）

1. 用 `mcp__Claude_Browser__preview_start(url=<父分析表 openUrl>)` 打开，先截图确认不是登录页。登录状态在应用重启或会话更换后可能失效：停在登录页时请用户在面板里登录（账号、验证码由用户输入，Claude 不代填、不导入 Chrome 凭证），不要当成页面故障。
2. 面板隐藏时请用户按 Cmd+Shift+B 显示。
3. 用 `find("<图名>")` 定位右侧步骤面板里的图表节点并点击，**等待 6–10 秒**再截图：首帧常是错位的过渡渲染，不能据此下结论。
4. 面板宽度会变，坐标随之变化：点击用 `find` 返回的 ref，`zoom` 前先截一张全图确定当前坐标。用 `zoom` 截取图表区域核对：系列数量与名称、堆叠顺序、颜色、数据标签与回读数字一致。
5. 只看不改：不展开左侧配置面板、不拖字段。展开配置会让页面进入“未保存”，之后导航被“离开此网站？”对话框拦住。

### Chrome 插件（默认）

- 只在自己创建的标签组里操作，不动用户已有标签；用户可能同时在看同一页面。
- 看板编辑器弹出「发现未保存更改：放弃 / 恢复」时两个都不点，告诉用户：点「恢复」会用旧草稿覆盖 MCP 刚保存的版本（K-34）。之后每次改版前重读 Markup，核对上次 MCP 保存的改动还在。
- 导航被“离开此网站”拦住时：标签是自己开的、且只做过查看和点击（联动、下钻、缩放），可放弃本地状态继续；若可能含用户的未保存改动，先问用户。
- 用户在旧标签页看到的是写入前的版本时，提醒刷新且不要在旧页面点保存，否则会用旧版本覆盖 MCP 写入。
- 看板效果用「预览」看；编辑态的组件虚线框不是实际样式。

### 标签页：一轮核验只留一个（D-045）

编辑器只要打开过（哪怕只是查看），页面就会被标成“未保存”，在同一标签页里跳转或刷新会被“离开此网站？”拦住。为了绕开弹窗每次都新开一页、看完不关，几轮下来用户的 Chrome 里会堆起十几个标签页，加载也越来越慢。

1. 只看效果时直接打开预览页（或父分析表页），不进编辑器；预览页不会被标成“未保存”，同一个标签页可以反复刷新、跳转。复用这一个标签页核验后续改版。
2. 只有要在界面里改配置（用户授权）时才进编辑器；改完保存，回到预览页核验，然后关掉编辑器标签页。
3. 「预览」按钮自己新开了一个标签页时，关掉原来的编辑器标签页，只留预览页。
4. 被“离开此网站”拦住时，不用新开标签页绕开：按上一节判断能否放弃本地状态，能放弃就在原标签页继续。
5. 每轮核验结束，关掉自己开的、不再需要的标签页，最多留一个给下一轮复用；不动用户自己的标签页。

看板「预览」打开后**至少等待 20 秒**再截图：图表有入场动画，过早截图会误判图形与截断（K-26）。指标卡检查第二行（对比值）是否被截断。
