# 分工：MCP 与浏览器、分析表与图表

两张表都按“已验证 / 待验证”区分。只有实际跑通过的才写成“已验证”；新步骤验证后把对应行从“待验证”挪上来。

## 一、MCP 与浏览器（D-007）

原则：**MCP 负责写，浏览器负责看。** 所有改动走 MCP，DSL 进日志，可复现可回滚；浏览器只做 MCP 看不到的事，不在界面里改配置。

| 事项 | 由谁做 | 状态 | 依据 |
|---|---|---|---|
| 列空间、项目、资产树 | MCP | 已验证 | list_spaces / list_projects / list_project_assets |
| 读字段、类型、样例、READY 状态 | MCP | 已验证 | get_project_asset_details |
| 值域、空值、Top 值探查 | MCP | 已验证 | profile_project_tables |
| 建/改分析表（筛选、公式、窗口、关联、打标签） | MCP | 已验证 | upsert_tables + 轮询 + 回读 |
| 建/改图表（编码、堆叠、排序、颜色、标签、名称） | MCP | 已验证 | upsert_charts 同名覆盖 |
| 图表聚合数字、排序配置核对 | MCP 回读 | 已验证 | 回读“编码 / 排序 / 预览数据” |
| 图形是否正确：系列是否被拆、堆叠顺序、系列名称显示 | 浏览器目视（Chrome 插件优先） | 已验证 | 回读预览是最细粒度查询结果，不代表渲染 |
| 颜色、样式、标签位置 | 浏览器目视（Chrome 插件优先） | 已验证 | 回读不返回样式 |
| MCP 没有写入工具的配置（参数、看板筛选器绑定） | 用户授权后由 Claude 在浏览器界面操作，完成后反读 | 已验证 | 例外于“浏览器只看不改”，见 D-026 |
| 登录、授权 | 用户本人 | 已验证 | Claude 不代填账号、验证码，不导入 Chrome 凭证 |
| 删除资产或项目、重命名、移动目录 | 用户在界面操作 | 已验证 | MCP 没有删除 / 移动工具；删除由用户确认执行 |
| 在界面里改图表配置 | 不做 | 已验证 | 展开配置即进入“未保存”，且改动脱离 DSL 与日志 |
| 看板布局、指标卡 | MCP 写，浏览器目视 | 已验证 | prepare_dashboard → upsert_dashboards，见 dashboard.md |
| 看板点击联动（同源组件） | 平台默认开启，无需配置 | 已验证 | 用户在看板点击数据块验证；见 dashboard.md「联动优先于筛选器」 |
| 项目参数 | 用户授权后在界面创建；MCP 只读 | 已验证 | 反读：`Param.yearMonth().defaultValues(…)` |
| 看板筛选器（绑参数 + 绑字段 + 控制范围） | 控件与样式：MCP Markup；绑定范围：MCP `enhance_dashboard_interactions`；绑参数：界面，放在看板最后一步 | 已验证 | 界面保存后看板可能不能再走 Markup（D-026） |
| 指标卡按参数算本期 / 上期 / 去年同期，指标算同环比 | 图表分支 + 指标 | 已验证 | 见 dashboard.md D-025 |
| 组件内下钻 | MCP `.drill(…)` 写，浏览器目视 | 已验证 | 第一级须在 x/y 或 col/row；点击即下钻 |
| 跨表联动 | MCP `enhance_dashboard_interactions`（或界面配置） | 已验证 | Markup 不表达联动；限制见 dashboard.md「跨表联动与筛选器绑定」 |
| 动态字段切换（`dynamicField` + 下拉框） | 字段定义：MCP 图表 query；切换控件：用户授权后在界面「绑定参数 → 动态字段」 | 已验证（切换效果待预览核验） | MCP 写不了控件、回读看不到绑定（K-35 ~ K-37，D-044） |
| 看板间钻取（drillDown） | — | 待验证 | 交互增强入口未开放 |
| 故事板 | MCP 写，回读核对 | 已验证（目视待验证） | upsert_storyboards 写 Markdown，get_project_asset_details 回读块结构；表格后的有序列表会重新编号（K-33） |
| 本地 Excel/CSV 上传导入 | MCP | 待验证 | prepare_data_file_imports → 上传 → import_data_file_tables |
| 业务口径沉淀 | MCP | 待验证 | shared_caliber |

## 二、分析表步骤与图表配置（D-008）

整体分层与“什么时候用什么”见 `dashboard-architecture.md`；本节保留逐项验证记录。

判断一句话：**定义“数据是什么”的放分析表，决定“这张图怎么呈现”的放图表。** 会被多张图复用、或代表业务口径的计算，一律放分析表。

计算再分三层（D-009）：

| 层 | 放什么 | 写法 | 不放什么 |
|---|---|---|---|
| 分析表步骤（数据集） | 原子字段与行级数据处理：清洗、打标签、窗口、关联 | `upsert_tables` 的 query | 汇总性、业务性指标 |
| 图表分支（图表 query，界面“高级模式”步骤） | 只服务这一张图的数据处理：专用筛选、按图表粒度聚合计算、聚合后计算（D-019） | `Chart.cross(query.from(...).groupBy(...).agg(...).formula(...))` | 不为了“多一个系列名”复制字段（R5） |
| 指标 | 汇总性、业务性指标（合计、比率等） | `.metric("<指标名>", "<聚合公式>")`，系列里引用 `metric("<指标名>")` | 行级处理 |

| 事项 | 放哪里 | 状态 | 说明 |
|---|---|---|---|
| 行级打标签（如客户分层、状态分类） | 分析表 formula | 已验证 | 口径，多图复用 |
| 跨行计算（如每个对象的首次发生时间） | 分析表：子查询 `groupBy(<对象>).agg(min(…))` + `join` 回明细 | 已验证 | **不要用 window min/max**：平台补 orderBy 成累计值（K-14、lint R8）；DATE 先转数值（K-03） |
| 跨表关联、纵向合并 | 分析表 join / union | 已验证 | 图表 query 禁止（lint R4） |
| 原始表加工后才能建图 | 分析表 | 已验证 | 数据源表不能直接挂图 |
| 时间粒度（按年 / 月） | 图表编码 `dim("<日期>").year()` | 已验证 | 不在 query 里预先按日期粒度 groupBy |
| 聚合方式（求和、计数） | 图表编码 `sum()` / `count("字段")` | 已验证 | 组件自带分组汇总，不重复聚合 |
| 系列组合（柱 + 线、堆积） | 图表 `.y(bar…)` `.y(line…)` `stacked` | 已验证 | — |
| 颜色维度、拆分哪个系列 | 图表系列级 `encode("color", …)` | 已验证 | 只写在要拆分的系列上 |
| 排序：横轴顺序、堆叠顺序 | 图表 `.sort(...)` | 已验证 | 分析表的 `.sort` 默认禁用、不决定展示顺序；堆叠顺序必须写（lint R2） |
| 颜色、圆角、曲线、标记、数据标签 | 图表 `.style(...)` / `encode("label")` | 已验证 | — |
| 系列显示名称 | 图表 `.as()`；同字段同聚合的第二个系列改用指标 | 已验证 | lint R1 |
| 汇总性 / 业务性指标（合计类） | 指标 `.metric("<指标名>", "SUM([<度量>])")` | 已验证 | 显示在图表编辑页左下“指标”面板，类型“聚合”；系列里 `metric("<指标名>")` |
| 只为某一张图服务的数据处理 | 图表 query（分支） | 已验证 | 在分析表步骤面板显示为该图专属分支；不在分支里造指标（lint R5） |
| 只影响某一张图的筛选 | 图表 query filter | 待验证 | 影响多图或代表口径时改放分析表 |
| 比率指标 | 指标 `.metric("<指标名>", "SUM([<分子>])/SUM([<分母>])")` | 已验证 | 按系列粒度计算；不对比率字段 sum |
| 指标能否跨图复用 | — | 待验证 | 目前只验证了挂在单个图表上的指标 |
| 数值格式（百分比等） | 图表 `.numberFormat(metric("<指标名>"), NumberFormatConfig.percentage(n))` | 已验证 | 可引用指标 |
| 双轴（金额与比率） | 图表系列 `.rightAxis()` | 已验证 | — |
| 参考线（均值、固定值） | 图表 `.referenceLine(…, SummaryType.AVERAGE / 固定值, …)` | 已验证 | 整体比率只能用固定值，取自 READY 回读结果 |
| 对象级散点粒度、大小、提示、透明度 | 图表散点系列 `encode("granularity" / "size" / "tooltip")`、`style("opacity")` | 已验证 | 写在系列上 |
| 对象级汇总表（每对象一行：合计、条件合计、去重计数、最近日期、距基准日天数） | 图表分支：`groupBy(<对象>).agg(…)` 聚合计算 + `.formula(…)` 聚合后计算；交叉表指标用 `sum()/max()` 透传 | 已验证 | 不新建分析表（D-019） |
| 条件聚合（近 N 期合计） | 图表分支度量过滤 `sum("<度量>").filter("<条件>")` | 已验证 | 指标公式 `SUM(IF(…))` 不可用（K-11） |
| 距基准日天数 | 图表分支聚合后 `.formula("DATESUBDATE(<基准日>, [<最近日期>], 'D')")` | 已验证 | 指标公式写法不可用（K-11） |
| 目标与实际对比（粒度不同） | 独立分析表：以目标表为主表，实际汇总到目标粒度后左关联；达成率用指标 | 已验证 | 见 dashboard-architecture.md 六（D-033） |
| 指标卡对比值的涨跌着色与箭头 | 图表分支算出对比字段，建图后 `Chart.edit` 追加 `.conditionalFormat(sum("<字段>"), …)` | 已验证 | 不能挂在指标上（K-22、lint R10） |
| 迷你趋势（近 N 期） | 图表分支 `filter(… @<参数> … COMBINEDELTA(@<参数>, -N, 'M'))` + 隐藏坐标轴 | 已验证 | 见 chart-dsl.md「迷你趋势」 |
| 固定类别颜色（主色 + 灰） | 图表 `.colorMapping(dim("<维度>"), {…})` | 已验证 | 看板视图复核（D-022） |
| 按条件给对象分组着色（如象限分类） | 分析表先按对象汇总并打标签，再在图表着色 | 待验证 | 分类是“数据是什么”，放分析表 |
