# 项目结构导图

用一张从左到右的思维导图说明一个项目“数据从哪来、经过哪些加工、挂了哪些图、图上定义了哪些指标、组件之间怎么跨表联动”（D-030）。用于项目复盘、交接和向客户讲解建模逻辑；不替代 MCP操作日志。

- 什么时候用

## 什么时候用

| 场景 | 画什么 | 之后 |
|---|---|---|
| 新需求进来、开发前（D-032） | 计划态：现有结构 + 拟新增 / 改动 / 删除的节点 | 用户确认后才写入资产 |
| 复盘、交接、向客户讲建模逻辑 | 现状 | — |

## 取数：从 MCP 读出结构

只用 MCP 读到的事实画图，不凭记忆补：

1. `list_project_assets`：源表、分析表、图表、看板的挂载关系。
2. `get_project_asset_definitions`（分析表 + 全部图表）：分析表的 `from / join` 决定表间箭头；图表 query 里有 `Query.from(...)` 管线的就是分支，`.label()` 是分支步骤名；`.metric()` 是图上指标；`@<参数>` 表示分支由参数驱动；`.drill()` 是组件内下钻。
3. `get_project_asset_details`（看板）或 `prepare_dashboard` 的 interactionReview：跨表联动的源组件、目标表与字段映射。

## 层级

从左到右五层，每层一列：

| 层 | 内容 | 写法 |
|---|---|---|
| 0 源表 | 导入的原始表 | 小号字，下方注明它对下游的作用（派生 / 作为主表） |
| 1 分析表 | 加工表、宽表 | 加粗；宽表注明“宽表” |
| 2 分支 | 图表的高级模式步骤 | 名称取分支的业务含义，下方小字注明分支类型与是否复用候选 |
| 3 图表 | 挂在分支或分析表上的图 | 加粗；有下钻的注明下钻路径 |
| 4 指标 | 图上 `.metric()` 定义的指标 | 普通字；未被任何系列引用的置灰并注明“未用” |

## 节点画法

- **直接挂表的图**：分支层画一个空心小圆点作为空节点，不写文字；图例里说明“空节点 = 直接挂表”。
- **同构分支合并**：多个图的分支步骤相同、只是度量不同（例如都按同一参数汇总本期 / 上期 / 同期），合并成一个节点，写“×N”，图表层同样合成“<图类> ×N”。
- **没有指标的图**：指标层写“无指标 · 字段在分支”并置灰，说明字段由分支直接产出。

## 连线画法

| 连线 | 含义 | 样式 |
|---|---|---|
| 树枝曲线 | 挂载关系：表 → 分支 → 图 → 指标 | 中性灰细曲线，左右展开 |
| 实线箭头 | 表间关系：源表 → 分析表；分析表之间的关联 | 箭头指向被生成的表；旁注“派生 / 汇总后关联 / 主表” |
| 虚线箭头（强调色） | 跨表联动 | **从源图表指向目标分析表本身**，不连到单张图；图例写明传值字段映射与“作用于目标表上直接挂表的图” |
| 括号 + 标签 | 同一指标在多张图重复定义 | 括住重复的指标，标“可共享” |

同表的天然联动不画。

## 判断规则

**分支归类**（分支层的小字类型）：

| 分支特征 | 标为 | 说明 |
|---|---|---|
| 按 `@<参数>` 过滤汇总（本期 / 上期 / 同期） | 参数联动 | 本质是由参数控制，不是换粒度；同构的合并为一个节点 |
| 换到新的对象粒度（`groupBy(<对象>)`）并产出多个字段 | 高级模式 · 子业务宽表 | 可服务多张图 |
| 只为一张图做的加工 | 高级模式 · 过程处理 | — |

**复用候选**：满足任一条即标——产出的是一张换粒度的小宽表（其他图也能挂）；或多个分支同构。标记表示“可沉淀为共享分支”，现阶段一分支一图时仍保留现状。

**可共享指标**：同名同公式的指标在两张及以上的图中各定义一次。

## 省略什么

- 很短、只服务一张图的过程处理分支（一两步筛选、改名）不单独画节点，图直接挂到上一层。
- 同表天然联动不画。
- 看板布局、样式、筛选器不画；筛选器 / 参数需要说明时另起一层，并与用户确认画法后再加。

## 计划态标记

- 已有且不动的节点：中性灰。
- 新增节点：强调色，名称后注“新”。
- 改动节点：保留原名，后注“改：<一句话改什么>”。
- 删除节点：加删除线，后注“删”。
- 新增的表间箭头、跨表联动同样用强调色，并写明关联键或字段映射。
- 图下单列“待确认”：需要用户拍板的口径（统计范围、粒度、基准日、对象定义），每条一行。

## 版式

- 左对齐的水平树，层与层之间留出曲线空间；节点是文字，不套方框，加粗区分表和图。
- 颜色只用两种语义色：分支类型 / 复用候选一种，跨表联动一种；其余中性灰。
- 底部图例：跨表联动、空节点、分支类型色，各一行以内。
- 一张图放不下时按分析表拆成多张，每张保留同样的五层。
