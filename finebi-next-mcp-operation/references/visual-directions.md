# 看板视觉方向库

按 `visual-style.md` 的场景评估从这里选方向（D-037）。每个方向只借给看板四样东西：**色板、密度、字号层级、一个标志性手法**；布局由“一个问题”决定，控件用平台标准控件。状态“已验证”表示在真实看板上做过并经用户认可；“未验证”的方向首次使用后补全写法与坑。

## 目录

- 选择速查
- 结构派：经营总览
- 刊物风：叙事汇报
- 台账式：数字为主
- 监控式：值守大屏
- 行业标准版

## 选择速查

| 场景信号 | 倾向 | 避开 |
|---|---|---|
| 管理层定期回顾，多指标、有目标与阈值 | 结构派、台账式 | 监控式 |
| 会上投屏讲故事、对外演示、分节叙事 | 刊物风、结构派 | 监控式 |
| 数字比图形重要（财务、经营月报、对账） | 台账式 | 刊物风 |
| 实时或高频刷新、远距离观看、值守 | 监控式 | 刊物风、台账式 |
| 用户要求“和 <某产品> 一样”、要稳妥 | 行业标准版 | — |

速查只给倾向；最后按场景评估的四行和防收敛自查定。

## 结构派：经营总览

- **状态**：已验证（A-13）。
- **适合**：管理层看“是否达标、差在哪”；有目标、有阈值；指标 4–6 个。
- **不适合**：叙事型汇报；只有一两个数字的场景。
- **手法**：灰作背景、只有一个主色系列；每个区块标题写结论；有目标的比率画达标 / 预警两条参考线（RAG）；指标卡带对比与红绿状态。
- **色板**：页面 `#F3F4F6`；组件白底 `1px #E5E7EB` 边、8px 圆角；主数据色 `#1F3A5F`；背景灰 `#D5D8DD`；目标灰 `#C9CCD1`；中性深色 `#1F2937`；状态 `#0CA30C` / `#D03B3B`；RAG `#28A745` / `#FFC107`。
- **风险**：最接近“经营看板”的品类默认样子；连用两个项目会雷同，必须靠标志性元素区分。

## 刊物风：叙事汇报

- **状态**：已验证（A-11）；版式细则见 `dashboard.md`「刊物风版式」（D-035）。
- **适合**：按章节讲一个故事；页面要像一份报告；组件少而精。
- **不适合**：指标多、需要快速扫读的场景。
- **手法**：组件与页面同色、无边框，指标卡用细线分隔；编号分节 + 节标题 + 细线；单一强调色贯穿节编号、表头、筛选器与图表。
- **色板**：纸色页面（如 `#F6F5F1`）；强调色一个（如 `#2B4C7E`）；图表同色系低饱和色；折线中性深色。
- **风险**：属于 AI 常见的“报刊风细线”外观；场景不是叙事时不选。

## 台账式：数字为主

- **状态**：已验证（A-14，用户认可首版）。已验证手法：节顶 2px 墨线 + 指标横带 `border-left:1px` 细线分隔；缺口图用 `colorMapping` 把“未达成”映射为缺口色、其余为灰。
- **适合**：读者主要看数字和差额；财务、经营月报、对账；明细表是主角。
- **不适合**：需要强视觉冲击的演示开场。
- **手法**：页面和组件同为白色，几乎无彩；图表系列用墨色与灰；**唯一的颜色只出现在“变化或缺口”上**（未达标的差额、恶化的指标）；指标卡是一条用细线分隔的横带，不做单独卡片；数字右对齐、单位小字。
- **色板**：页面 `#FFFFFF`；分隔线 `#E7E5E4`；墨色 `#1C1917`；灰 `#A8A29E` / `#D6D3D1`；缺口色一个（如 `#B91C1C`），好的方向用灰或深绿。
- **风险**：过度克制会显得单薄；必须有一个标志性元素承担视觉重心。沿用的旧图（尤其有界面专属设置、不能重写的）颜色会跳出色板，需在档案里记为偏离。

## 监控式：值守大屏

- **状态**：未验证；深色主题在当前 MCP 版本能否设置待查（K-12）。
- **适合**：实时数据、远距离观看、异常优先。
- **不适合**：会议汇报、需要细读的分析。
- **手法**：深色底，层级只靠明度；颜色只在数据和状态上；异常项放大并置顶。
- **色板**：底 `#0B0F14`，组件 `#111827`；数据色一个高明度色；状态色按底线。
- **风险**：在浅色会议投屏中可读性差。

## 行业标准版

- **状态**：兜底选项。
- **适合**：用户明确要求稳妥、要与某个已知产品一致，或时间极紧。
- **手法**：平台默认主题 + 规整网格 + 底线；按用户点名的参照产品的完成度执行，不夹带花样。
- **注意**：只有用户提出或场景明确需要时才选；自主选择时它是防收敛自查里要避开的那个。
